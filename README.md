# 🔐 Password Strength Checker

A simple Python application that checks password strength and provides suggestions for creating more secure passwords.

## Features

- Password strength analysis
- Security score
- Helpful improvement tips
- Beginner-friendly Python project

## Requirements

- Python 3.x

## Run

```bash
python password_checker.py
```

## Example

Enter your password:
```
Hello123
```

Output:
```
Strength : Medium
Score    : 5/7
Suggestions:
- Add at least one special character.
```
